# 试炼密室版本兼容性

试炼密室结构起点的放置规则在已检查版本中保持不变，但内部房间池从 24w33a 开始发生变化。因此，同一种子的密室起点可以相同，刷怪笼坐标和数量仍会不同。

## 版本边界

| 世界版本 | 布局代际 | 对应构建 |
|:---|:---|:---|
| 1.21、1.21.1 | 旧布局 | 1.21.1 稳定分支 |
| 1.21.2 现代布局 | 现代布局 | `feature/trial-modern-generation` |
| 26.2 实验运行时 | 现代布局 | `experiment/trial-26.2-benchmark` |

24w33a 新增了五个 hallway encounter 模板并修改三个试炼密室模板池；1.21.2 是包含这些变化的第一个正式版。固定种子回归显示 1.21.2 与 26.2 的当前样本结果一致；26.2 的 Java API 和构建方式已经改为未混淆官方类名。

稳定现代构建固定使用 Minecraft 1.21.2 官方服务端运行时；26.2 目前只在实验分支验证。

## 回归样本

种子 `8050192242802360875`、搜索中心 `0,0`、搜索半径 `5000`：

- 1.21.1 和 1.21.2 均枚举出 266 个相同的结构放置候选。
- 结构起点 `2216,-1064` 在 1.21.1 布局中统计到 20 个刷怪笼，在 1.21.2 布局中统计到 29 个。
- 结构起点 `3432,2392` 在 1.21.1 布局中统计到 31 个刷怪笼，在 1.21.2 布局中统计到 18 个。
- 1.21.2 与 26.2 均枚举出 266 个候选；两者输出的 101 条结果 CSV 完全一致。
- 同一台 16 逻辑处理器机器、GraalVM 25、14 个精细线程下，1.21.2 为 `54.5 座/秒`，26.2 为 `104.7 座/秒`。单次小样本仅用于判断方向，不代表所有种子和机器。

这组样本用于确认现代构建确实加载了新版模板池，而不是只修改版本号。
